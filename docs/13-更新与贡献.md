# 反馈与建议

公开版只提供 EXE 与说明，不在本仓库提供源码或源码补丁。

## 可以反馈什么

- 使用问题、报错、兼容性
- 新的 Steam CDN 域名、校园网 DNS 行为
- 文档错别字、断链、表述不清
- 对界面、提示、报告的建议

## 不要提交什么

- 第三方二进制、安装包、DLL、EXE、证书、私有密钥
- 个人隐私、真实姓名、学号、完整 IPv6 地址、Steam 账号、Cookie
- 绕过校园网认证、计费、流量管理、账号共享的功能请求
- 移除学习用途声明、归属行、许可的改动

## 反馈方式

开 GitHub issue，附：

- Windows 版本
- 使用的 EXE 版本
- 校园网 / IPv6 环境
- 复现步骤
- 脱敏后的程序窗口输出或 `--report` 报告

不要为了反馈问题公开上传完整日志；先自行检查是否包含敏感信息。

## 版本

公开版当前 `1.0.0`。新版本由维护者发布，EXE 与说明同步更新。
