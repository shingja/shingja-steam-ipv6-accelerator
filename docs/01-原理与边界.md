# 原理与边界

## 一句话

用 hosts 把 Steam 当前使用的下载 CDN 域名指到本机回环地址；本机程序监听 80 端口，把连接转发到该 CDN 的 IPv6 节点。Steam 看到的是本地 IPv4 连接，实际数据走 IPv6。

```text
Steam
  │  HTTP / IPv4 / 127.0.0.20:80
  ▼
本地转发器（本工具）
  │  TCP / IPv6 / [2001:da8:...]:80
  ▼
Steam CDN 节点
```

## 为什么不能只改 hosts

Steam 客户端自带 IPv6 连通性检测。如果 hosts 把 CDN 域名直接指向一个 IPv6 地址，Steam 的检测逻辑可能把下载降级成 `ipv4-only`，日志里会出现：

```text
IPv6 Connectivity state has changed, downgrading to ipv4-only
```

所以必须让 Steam 认为自己在连一个本地 IPv4 地址，实际由本机转发器走 IPv6。

## 设计要点：四个容易踩的坑

### 1. 系统 DNS 可能不返回 AAAA

校园网 DNS（如 `202.204.52.94`）可能不返回 CDN 域名的 AAAA。只依赖系统 DNS 时，解析为空，转发器没有上游，Steam 就表现为“无下载源 / Content unavailable”。

**本工具**：直接向多个 IPv6 公共 DNS（阿里 `2400:3200::1`、腾讯 `2402:4e00::`、Google、Cloudflare）查询 AAAA，绕开系统 DNS 的这条限制。

### 2. CDN 域名会变

CDN 域名会随调度变化，硬编码列表迟早失效。

**本工具**：从 Steam 官方内容服务器目录 API 动态获取当前域名：

```text
https://api.steampowered.com/IContentServerDirectoryService/GetServersForSteamPipe/v1/?cell_id=46&max_servers=40&format=json
```

API 不可用时使用内置大陆 CDN 备用列表。

### 3. 单点失败会挂起整个下载

如果所有域名都指向本地代理，某个域名上游拿不到 IP 时，连接会挂起，Steam 不会换源。

**本工具**：只映射实测可用的域名；转发失败立刻返回 `502 Bad Gateway`，让 Steam 自动换源。

### 4. 302 跳转域名会造成 IPv4 泄露

CDN 会 302 跳转到二级域名，例如：

- `xz.sycontroller.com`
- `gstore.val.smogfly.com`
- `gstore.val.manlaxy.com`

只写主域名，这部分流量仍然走 IPv4。**本工具**内置已知跳转域名，并从 Steam `logs/content_log.txt` 中自动发现新的跳转域名。

## 选点流程

1. 获取候选域名：Steam API + 备用列表 + 已知二级域名 + 日志发现的域名。
2. 对每个域名向多个 IPv6 DNS 查询 AAAA，得到多个候选地址。
3. 对每个 `(域名, IP)` 发一个 HTTP 探测请求。
4. 判定可用：`200`、`206`、`403`、`416`，或非广告/劫持域名的 `301/302/307/308`。
5. 按延迟排序，每个域名选最快可用节点。
6. 仍无节点的域名，用 IPv4 公共 DNS 补充候选后再试。
7. 只把有可用节点的域名写入 hosts。

## 本机转发

- 每个域名分配一个回环地址：`127.0.0.20`、`127.0.0.21`、……
- 监听 `80` 端口（Steam 大陆 CDN 当前是 HTTP 节点）。
- 上游连接使用 `AF_INET6`，只连解析出的 IPv6 地址。
- 双向管道复制数据；连接失败返回 502。
- 计数器按域名统计字节数与连接数。

## 边界

- **仅 Windows**：依赖 `C:\Windows\System32\drivers\etc\hosts`、注册表、`ipconfig`。
- **仅 Steam 下载 CDN**：不代理网页、商店、联机、语音。
- **需要 IPv6 出口**：校园网没有 IPv6 时无法使用。
- **部分 CDN 没有 IPv6**：例如 `trts.baishancdnx.cn`，这部分仍走 IPv4。
- **速度不保证**：与 IPv4 直连相当是实测结果，不是承诺；高峰期、节点负载、学校出口策略都会影响。
- **不绕过计费/认证**：只改变下载流量的 IP 协议出口。使用前确认符合学校网络管理规定。
- **DNS 未使用 DNSSEC/DoH**：AAAA 查询走 UDP 53，理论上可被链路攻击者伪造；在可信校园网内使用。

## 为什么不用其他方案

| 方案 | 问题 |
|---|---|
| 只改 hosts 指向 IPv6 | Steam 自带检测会降级成 IPv4 |
| 系统级 VPN / 代理 | 影响所有流量，可能违反校园网规定，配置复杂 |
| 修改 Steam 客户端 | 侵入性强、随更新失效、有账号风险 |
| 本地 HTTP 代理 + PAC | Steam 下载不一定遵守 PAC；仍需处理 IPv6 解析 |
| 本工具：hosts + 回环转发 | 侵入性小、可还原、只影响指定 CDN 域名 |

## 与第三方工具的关系

本工具不内嵌、不分发 Steamcommunity_302、UsbEAm Hosts Editor 或任何第三方二进制。它们解决的是不同问题：

- **Steamcommunity_302**：Steam 社区访问重定向。
- **UsbEAm Hosts Editor**：手动编辑 hosts 的图形工具。
- **本工具**：Steam 下载 CDN 的 IPv6 转发。
