# 故障排查

## 先做环境诊断

```bat
SteamIPv6Accelerator-v1.0.0.exe --diagnose
```

会检查：

- Steam 安装目录
- 系统代理状态
- IPv6 DNS 查询是否可用
- IPv6 出口是否可用
- 候选 CDN 域名数量

## 症状表

| 症状 | 可能原因 | 处理 |
|---|---|---|
| 启动即报 DNS 解析失败 | 本机 IPv6 不通；或 DNS 被拦 | `ping -6 ipv6.baidu.com`；换网络；运行 `--diagnose` |
| 列出 0 个可用域名 | 校园网没有 IPv6；或 DNS 被拦 | 检查 IPv6；换网络；运行 `--diagnose` |
| Steam 一直“无下载源” | 未重启 Steam；系统代理未关；hosts 未写入 | 重启 Steam；关代理；检查 hosts 标记块 |
| 加速后速度没变 | 该 CDN 节点本来就不快；IPv6 出口限速 | 停止加速，回 IPv4 对比；换时间段 |
| 加速后更慢 | IPv6 节点拥堵 | 按回车停止；Steam 会自动换源 |
| hosts 没还原 | 窗口被强杀；程序异常 | `SteamIPv6Accelerator-v1.0.0.exe --restore` 或 菜单 `2` |
| `PermissionError` / 写入 hosts 失败 | 没有管理员权限 | 右键 `SteamIPv6Accelerator-v1.0.0.exe` → 以管理员身份运行 |
| `python` 不是内部或外部命令 | Python 未加入 PATH | 重装 Python，勾选 Add to PATH；或使用 `py -3` |
| 端口 80 被占用 | 其他 Web 服务 / 代理 | 关闭占用程序；`netstat -ano | findstr :80` |
| 系统代理关不掉 | Clash / v2rayN 的 TUN 模式 | 退出代理软件，或关闭 TUN / 系统代理 |
| 某些域名没有加速 | 无 AAAA 记录或探测失败 | 正常；程序会跳过，不影响其他域名 |

## 检查 IPv6

```bat
:: 是否有 IPv6 地址
ipconfig

:: 是否能走 IPv6
ping -6 ipv6.baidu.com

:: 查 CDN 域名的 AAAA
nslookup -type=AAAA xz.pphimalayanrt.com 2400:3200::1
```

`nslookup` 应返回 `AAAA` 记录。没有记录，说明该域名当前没有 IPv6 节点。

## 检查 hosts

用管理员权限打开：

```text
C:\Windows\System32\drivers\etc\hosts
```

加速期间应只有一段：

```text
# ===== SteamIPv6-Download BEGIN (auto) =====
127.0.0.20 xz.pphimalayanrt.com
...
# ===== SteamIPv6-Download END (auto) =====
```

如果看到非 `127.0.0.x` 的地址、无关域名，立即：

```bat
SteamIPv6Accelerator-v1.0.0.exe --restore
```

## 检查 Steam 日志

路径通常是：

```text
<Steam 安装目录>\logs\content_log.txt
```

搜索：

```text
127.0.0.
```

应能看到连接到本机转发器的记录。也可以搜索：

```text
IPv6 Connectivity state has changed
```

如果出现 `downgrading to ipv4-only`，说明 Steam 走了纯 hosts 方案或被降级；确认你用的是本工具的回环转发，而不是只改 hosts。

## 检查端口占用

```bat
netstat -ano | findstr :80
```

如果 `127.0.0.20:80` 等地址被其他程序占用，关闭该程序，或重启电脑后先启动本工具。

## 检查系统代理

```bat
reg query "HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings" /v ProxyEnable
```

`0x1` 表示开启。关闭 Clash / v2rayN 的“系统代理”开关，或让本工具临时关闭。

## 完全重置

如果状态混乱：

1. 停止所有 Steam 和代理软件。
2. 运行 `SteamIPv6Accelerator-v1.0.0.exe --restore`。
3. 检查 hosts 没有残留。
4. 重启电脑。
5. 重新运行 `SteamIPv6Accelerator-v1.0.0.exe`。

## 仍然不行

开 issue 时附：

- Windows 版本
- Python 版本（`python --version`）
- 是否校园网 / 是否有 IPv6
- `--diagnose` 输出
- 脱敏后的 `content_log.txt` 片段
- 具体症状与复现步骤

不要贴真实姓名、学号、完整 IPv6 地址、Steam 账号、Cookie 或支付信息。
