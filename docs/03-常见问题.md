# 常见问题

## 加速后 Steam 还是“无下载源”

按顺序试：

1. 在程序窗口按回车停止，或运行 `SteamIPv6Accelerator-v1.0.0.exe --restore`。
2. 完全退出 Steam（托盘也退出），重新启动。
3. 确认系统代理已关闭。
4. 重新运行 `SteamIPv6Accelerator-v1.0.0.exe`，选 `1`。
5. 看程序是否列出至少一个可用域名；一个都没有，说明 IPv6 出口或 DNS 有问题。
6. 运行 `SteamIPv6Accelerator-v1.0.0.exe --diagnose` 看诊断。

## 加速后下载反而变慢

正常。IPv6 节点可能拥堵，或学校出口对 IPv6 限速。按回车停止，Steam 会回到 IPv4。速度与 IPv4 直连相当是实测结果，不是承诺。

## 真的走 IPv6 了吗

看三处：

1. 程序窗口列出的上游地址是 `[2001:...]` 或 `[240e:...]` 等 IPv6 字面量。
2. Steam `logs/content_log.txt` 里出现 `127.0.0.20`、`127.0.0.21` 等本机地址。
3. 程序窗口的累计流量随下载增长。

注意：Steam 自带的 IPv6 检测会把“纯 hosts 指向 IPv6”降级成 `ipv4-only`，所以不能只看 Steam 设置里的 IPv6 开关。

## hosts 没还原

双击 菜单 `2`，或：

```bat
SteamIPv6Accelerator-v1.0.0.exe --restore
```

程序只删除 `# ===== SteamIPv6-Download BEGIN/END =====` 之间的内容，不动其他 hosts 条目。

如果还原后仍有问题，打开 `C:\Windows\System32\drivers\etc\hosts`，确认没有残留的 `127.0.0.20` 等条目。

## 提示“需要管理员权限”

右键 `SteamIPv6Accelerator-v1.0.0.exe` → **以管理员身份运行**。或者在 Windows 设置中允许程序提权。

## 提示找不到 Python

安装 Python 3.9+，安装时勾选 **Add python.exe to PATH**。然后新开一个命令行窗口再试。

## 开着 Clash / v2rayN 能用吗

必须先关闭“系统代理”。Steam 会跟随系统代理走海外节点，IPv6 加速不会生效。程序会询问是否临时关闭，退出时恢复。

如果代理软件使用 TUN / 虚拟网卡模式，可能仍会接管流量；此时需要退出代理软件，或在其规则中让 Steam 下载直连。

## 会封号吗 / 会被 VAC 吗

本工具不修改游戏文件、不注入 Steam 进程、不读写游戏内存、不伪造账号信息。它只改变下载 CDN 的连接路径。按 Steam 用户协议和学校网络规定使用；风险由使用者自行承担。

## 支持哪些游戏

所有通过 Steam 内容下载 CDN 下载的游戏和更新。创意工坊、商店、社区、联机不走本工具。

## 为什么只监听 80 端口

Steam 大陆 CDN 当前使用 HTTP 80 节点。`https_support == "mandatory"` 的节点会被跳过，因为本工具不做 TLS 终止。

## 为什么有些域名没有加速

可能原因：

- 该域名没有 AAAA 记录；
- 所有 IPv6 候选都探测失败；
- CDN 节点在维护；
- 域名是 302 跳转后的二级域名，但日志里还没出现。

程序会跳过不可用域名，不会让整个下载卡死。

## 可以同时用 Steamcommunity_302 吗

可以，但两者都会改 hosts 或网络设置，建议先分别确认可用，再组合使用。本仓库不内嵌、不分发 Steamcommunity_302，请从官方渠道获取并遵守其许可。
