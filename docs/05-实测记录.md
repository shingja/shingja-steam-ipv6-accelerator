# 实测记录

## 2026-10-31 · 北京科技大学校园网 CERNET2

### 环境

| 项 | 值 |
|---|---|
| 网络 | 校园网 CERNET2 |
| 本机 IPv6 | `2001:da8:208:38:...`（仅保留校园前缀） |
| 系统 DNS | `202.204.52.94`（不返回 CDN 域名的 AAAA） |
| 系统 | Windows 11 |
| Steam | 大陆 CDN，HTTP 80 节点 |
| 工具版本 | 1.0.0 |

### 测试目标

验证在校园网 DNS 不返回 CDN 域名 AAAA 的情况下，本工具能否完成解析、选点、写入 hosts 并让 Steam 下载走 IPv6。

### 实测结果

- 自动选出 **14 个** CDN 域名可走 IPv6。
- Steam 下载日志确认连接到 `127.0.0.20/21/22:80` 本机转发器。
- 上游示例：`xz.pphimalayanrt.com` 走 `2001:da8:20d:40da:3::12`。
- 删除测试文件后，Steam 校验并成功重新下载。
- 实测下载速率约 **72–80 Mbps**，与 IPv4 直连相当。
- 全程未发现主域名 IPv4 泄露。

### 日志片段（脱敏）

```text
[运行中] 累计 1024.0 MB | 当前 9.38 MB/s | 连接 8 个 | 加速域名 14 个
```

Steam `content_log.txt` 可见类似：

```text
Connecting to 127.0.0.20:80
```

### 注意事项

- Steam 客户端自带的 IPv6 连通性检测会把“纯 hosts 指向 IPv6”的方案降级成 `ipv4-only`：

  ```text
  IPv6 Connectivity state has changed, downgrading to ipv4-only
  ```

  所以必须采用本工具的本机转发方案，不能只改 hosts。

- 部分 CDN 二级跳转域名（例如 `trts.baishancdnx.cn`）本身没有 IPv6 节点，这部分数据仍走 IPv4，属于 CDN 侧限制。

- 测速结果受时间段、节点负载、学校出口策略影响，不代表任何承诺。

## 复现方法

```bat
SteamIPv6Accelerator-v1.0.0.exe --diagnose
SteamIPv6Accelerator-v1.0.0.exe --start
```

下载一个已拥有的游戏或更新，观察程序窗口与 Steam `logs/content_log.txt`。
