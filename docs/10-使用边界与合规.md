# 使用边界与合规

## 一句话

**这是学习网络协议与网络工程的项目，不是绕过校园网认证、计费或流量管理的工具。**

## 学习目的

本项目用于学习和演示：

- IPv6 地址解析、AAAA 记录与公共 DNS；
- hosts 文件的作用与可还原修改；
- 本机 TCP 转发、回环地址、端口监听；
- Steam CDN 调度、302 跳转与内容校验；

适合在课程设计、实验室、自建网络或个人设备上做实验。

## 允许的用法

- 在自己拥有或获授权的设备上学习、测试；
- 在自建 IPv6 网络 / 实验环境中验证原理；
- 阅读公开说明、使用 EXE，并遵守 [LICENSE](../LICENSE) 与 [NOTICE](../NOTICE.md)；
- 在符合学校网络管理规定的前提下，优化自己账号的下载路径。

## 明确禁止

- **绕过校园网认证、计费、流量管理或出口策略**；
- **代下、代加速、账号共享、出租、转售、商业分发**；
- 把本工具打包成“免流量”“破解”“内部版”等误导性产品；
- 对校园网进行扫描、攻击、干扰、规避审计；
- 任何违反学校规定、Steam 用户协议或当地法律的使用。


## 校园网政策优先

学校网络管理规定优先于本项目的任何说明。不同学校、不同时期对 IPv6 流量、P2P、下载工具、hosts 修改、代理的认定可能不同。

使用前请自行确认：

1. 学校是否允许修改 hosts / 使用本地转发；
2. 校园网 IPv6 流量是否独立计费、是否限速、是否禁止特定用途；
3. 是否允许在个人设备上运行此类工具；
4. 是否需要向网络中心报备。

不确定时，先问学校网络中心，或只在自建实验环境学习。
