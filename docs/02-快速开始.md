# 快速开始

> 公开版只提供单文件 EXE。双击即可，不需要安装 Python，也不需要 BAT。

## 1. 检查环境

- Windows 10 / 11
- 校园网已启用 IPv6（CERNET2）
- 修改 hosts 需要管理员权限，程序会请求提权

检查 IPv6：

```bat
ping -6 ipv6.baidu.com
```

能 ping 通说明有 IPv6 出口。

## 2. 启动

双击根目录的 **`SteamIPv6Accelerator-v1.0.0.exe`**。

菜单：

```text
1  开始 IPv6 加速
2  还原 hosts
3  环境诊断
4  打开 GitHub 项目
0  退出
```

输入 `1` 回车。

首次加速会显示学习用途声明，要求输入 **“同意”** 后才继续。确认记录只保存在本机，不联网、不上传。

## 3. 处理系统代理

如果检测到系统代理，按提示选择是否临时关闭。**必须关闭系统代理，Steam 才会走 IPv6。**

## 4. 等待选点

程序会获取 Steam CDN、查询 IPv6 DNS、探测选点、写入 hosts、启动本机转发器。约 10–40 秒。

## 5. 重启 Steam 并下载

**完全退出 Steam**（托盘图标也要退出），再启动。开始下载，保持程序窗口打开。

## 6. 停止与还原

下载完成后在窗口按 **回车**。程序会停止转发、删除 hosts 加速条目、刷新 DNS。

异常退出时：

- 双击 exe，菜单选 `2`
- 或运行 `SteamIPv6Accelerator-v1.0.0.exe --restore`

## 命令行速查

```bat
SteamIPv6Accelerator-v1.0.0.exe --diagnose
SteamIPv6Accelerator-v1.0.0.exe --restore
```
