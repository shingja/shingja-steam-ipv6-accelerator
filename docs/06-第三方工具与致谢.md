本仓库**不内嵌、不分发**任何第三方软件、二进制、证书、日志或私有密钥。下面只给官方来源，方便你自行获取。

## Dogfight360 / 羽翼城

本项目站在 Dogfight360（羽翼城）公开工作的基础上：

- **下载 CDN 重定向 IPv6/IPv4 工具包**（Steam / Epic / Battle.net / UbiConnect / Xbox PC）
  官方页面：http://www.dogfight360.com/blog/18273/
  该工具已被作者标记为【过期】，并被 **UsbEAm 游戏下载助手** 取代。本项目针对校园网 DNS 不返回 AAAA 的情况做了处理。
- **UsbEAm 游戏下载助手**：作者当前主推的下载加速工具，带 UI、IPv4/IPv6 可用性检测、CDN 优选。
  官方分类页：https://www.dogfight360.com/blog/category/steamoriginuplay/

本项目是在其公开思路基础上的**修复与重写**，不是官方续作，也不代表 Dogfight360 背书。原工具的版权与许可归 Dogfight360 所有。

## Steamcommunity_302

Steam 社区 / 商店访问重定向工具，作者 Dogfight360 / 羽翼城。

- 官方页面（当前版本）：https://www.dogfight360.com/blog/18682/
- 官方功能说明：https://www.dogfight360.com/blog/knowledge-base/steamcommunity_302_13_manual/

与本项目的关系：解决的是不同问题。它处理 Steam 社区访问，本项目处理 Steam 下载 CDN 的 IPv6 转发。可以组合使用，但请先分别确认可用。

## UsbEAm Hosts Editor

多平台 hosts 编辑与 CDN IP 测速工具，作者 Dogfight360 / 羽翼城。

- 官方页面：https://www.dogfight360.com/blog/18627/

与本项目的关系：它适合手动挑选 CDN IP；本项目自动发现域名、解析 AAAA、探测选点并启动回环转发。两者都会修改 hosts，组合使用时注意不要互相覆盖。
